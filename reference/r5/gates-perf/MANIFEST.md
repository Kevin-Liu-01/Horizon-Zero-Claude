# reference/r5/gates-perf — licence-clean reference set

Licence-clean pose and framing references for the carried Round-4 visual rows (`tools/gates.r5.carried.mjs`) that gates-perf re-staged: the kept-system rows R33 (c) grades at W0a (V1–V4, V12–V14, V21) and the slots the lance rows already name (V46–V49, melee re-stages them at W1). They replace the deleted Round-4 stills (top-level `reference/MANIFEST.md`). A judge compares body mechanics and framing, never costume or likeness.
